# 苏东坡的下午茶 · 东坡行旅

一个以苏轼（苏东坡）生平游历为题材的互动叙事小游戏 / 网页作品。玩家跟随苏东坡的行旅路线，体验宋代文人雅集、茶事与市井烟火。

## 内容

- 互动叙事网页（HTML / CSS / JavaScript）
- 手绘风格场景、立绘、菜牌、匾额等美术素材
- 背景音乐与音效

## 目录结构

- `行旅.html` / `行旅.js` / `行旅.css` / `行旅数据.js`：游戏主程序与数据
- `素材/`：图标、立绘、菜牌、音乐、音效、高清图等美术资源
- `调研/`：历史考证资料
- `概念板.html` / `风格对照.html` / `风格实机mock.html` / `灶前.html` / `音效自检.html` 等：概念与验证页面

## 说明

本仓库仅包含游戏本体（「东坡行旅」目录）。

工作区中其余内容（产图与校验脚本 `tools/`、运行截图与日志 `_shots/`、代码备份 `_backup/`、参考图、视频等）不参与版本管理，已在 `.gitignore` 中忽略。
