## 为什么要

用户 9-27 否掉了右侧那座深色博古格（`hold-hang2-1`，369×587，六个开口大小不一），
换成了 `alt-hang-3`（407×272，一根横梁垂五枚空白木札）。**观感问题解决了**：
不再是一件家具压在画面上，改成挂在素墙上的东西。

但它是**横的**，而右栏能给的净空是一条竖带：

| | 现在的算法 |
|---|---|
| 画幅 | 1280×720 |
| 木札框左界 | x 950（再往左会压到席间三位的肩，`.seated` 已从 `right:246` 收到 `right:340` 让位） |
| 可用宽 | 1280 − 950 = **330 px** |
| 一枚札宽 | 330 × 0.10 = **33 px** |
| 要写的数 | 「400」「0/4」「12 状」—— 13 px 字号刚好顶满，超一个字符就要被 `fitShelf()` 缩字号 |

也就是说：**现在能用，但没有余量**。牌名一长（「定州空印 3 状」这种）就写不下，
只能像现在这样把「风险／空印／已借」挪到牌区上方那行提示里去。

## 要什么

**一根立柱（或一枚墙钉）上垂五枚竖长木札，纵向排成一列**，适配 300×560 左右的竖带。
这样一枚札能拿到 ~52 px 宽 × ~100 px 高，竖排两字 + 一个三位数 + 一个小注都放得下。

- 前缀建议 `hangv`（四张候选一批，命名 `hangv-1..4`）
- 比例 **9:16**（竖幅反而出图最大，产图那边量过：9:16 → 1350×2400）
- 五枚札的**牌面必须完全空白**，不许有任何字 —— 字全部由 HTML 叠（即梦写不出可靠汉字）
- 札与札之间**不要相互遮挡**，纵向间距要匀：格位要用 `tools/measure_slots.py boxes` 量得出来
- 绳/钉可以有两处，但**别画在牌面上**（现在 `alt-hang-3` 的绳孔就在牌顶，字得往下让 16%）

## 提示词（身份句放最前，这是 §42 那条教训的正面写法）

```
古风厚涂道具：一根深色立柱上钉着一条横木，横木上垂下五枚竖长木札，纵向排成一列，
札与札之间留匀距、互不遮挡。每枚木札的牌面完全空白、素净浅米色、边缘微微磨损，
上下两端各钻一个绳孔，麻绳系在横木上。背景纯白、无渐变、无投影、无家具、无人物。
牌面上不许出现任何文字、符号、印章、图案。
```

⚠ 三条已知的即梦脾气（产图那边自己记过，这里只是提醒别踩）：
1. 「横向并排四格」会被压成一格 —— 这次是**一物一图**，不涉及；
2. 否定指令不可靠：写「不许有字」仍可能落字，**要逐项枚举**（文字／符号／印章／图案）；
3. 名词会被扩成色块 —— 「木札」这种具体器物名比「标签」稳。
