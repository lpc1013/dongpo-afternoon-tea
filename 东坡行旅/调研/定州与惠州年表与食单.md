# 定州与惠州年表与食单

> 体例照《后半生年表与食单.md》：每条事实尾标【有据】（有篇名可引）／【传说】（明清话本、笔记小说附会）／【存疑】（说法不一或未核到）。宁可标存疑，不凑数。
>
> 范围：祐（1093）知定州 → 绍圣元年（1094）贬惠州 → 绍圣三年（1096）迁白鹤峰 → 绍圣四年（1097）四月离惠赴儋之前。
>
> **纪年提醒**：委托单里写"元丰八年（1085）苏轼知定州"有误——元丰八年苏轼知登州；知定州在**元祐八年（1093）**（宋人记"二年定州"自注、《苏轼年谱》卷二十七）。本文档按 1093—1094 记【有据】。

## 二、食单

### 定州（1093—1094）

- **总判：未核到可靠食单。** 已查方向：定州时期诗文（《雪浪石》及诸题咏）、《乞增修弓箭社条约状》语境、今人定州考证文（燕赵都市报/新浪 2025、华西都市 2025）。所得只有酒与果栗，无一道可确证的"定州菜"。游戏若需定州食单，只能用以下三条，不得虚构。
- **中山酒（州土之酒，非其所酿）**：张舜民（时接知定州）悼苏轼诗"满酌中山酒，重添丈八盆"【句有据（今人定州考证文所引），挽诗全篇题名下文未核【存疑】】。它只证明"中山酒"为定州名物，**不能证明此酒为苏轼所酿**（松醪问题见第四节）。
- **黄柑、烝栗**："燕南异事真堪纪，三寸黄柑擘永嘉""寄君东阁闲烝栗，知我空堂坐画灰"——定州时寄惠诗中之句【句据今人考证文所引【存疑，篇名未核到】；若核实确为定州作，则可入戏：河北官斋冬日吃烤栗、剥温州柑，反常的"北地南方味"】。
- **戒酒自述**："杯勺不入于口"语（谪定期自述戒酒的延伸，前档已挂《谢放罪表》语境）【存疑——篇名沿用前档未复核，勿当定州实名菜写】。

### 惠州（1094—1097）

- **荔枝**："罗浮山下四时春，卢橘杨梅次第新。日啖荔枝三百颗，不辞长作岭南人。"【有据，《食荔枝二首》其二】"卢橘"即枇杷【有据，传统注】。是**他写的**。
- **烤羊脊骨**：《与子由书》"不敢与仕者争买，时嘱屠者买其脊骨……点薄盐，炙微焦食之……然此说行，则众狗不悦矣"【有据】。是**他写的**。
- **东坡羹**：《东坡羹颂并引》自记法（菘、苦蔓菁、萝卜，不用肉）【有据，篇名在他集中；是否惠州所作未核【存疑】】。是**他写的**（法），站点存疑。
- **东陂种稻**："东陂雨一尺，水满稻苗新"（大意）——白鹤峰东陂事【有据，惠州诸诗；句读各本小异，下字以中华书局《苏轼诗集》为准】。
- **卓锡泉酿酒/烹茶**：卓锡泉为惠州史实名胜（唐僧卓锡成泉之说见方志），但**苏轼文集中未核到以卓锡泉为题之篇**；"以卓锡泉酿酒"多见于明清方志与今人演绎【传说】。游戏可写"城中有卓锡泉"（地理真实），不可写"苏轼用此泉酿酒"（无据）。
- **未核到**：惠州时期的具体菜肴名目，除荔枝、羊脊骨外，方向已查《与王敏仲书》诸药帖（多论养生节食，不列菜）——不凑数。

## 四、易错纠正

| 常见说法 | 实际情况 | 依据 | 判定 |
|---|---|---|---|
| "苏轼元丰八年（1085）知定州" | 1085 是知**登州**（任仅五日）；知定州在**元祐八年（1093）**八月九月到任 | 《宋史·苏轼传》编年 | 纠正【有据】 |
| "日啖荔枝三百颗＝他真的一天吃三百颗"／把荔枝与"一骑红尘"皇家快递混讲 | "三百颗"是诗家夸张语（"不辞"二字明是假设）；"一骑红尘妃子笑"是杜牧咏杨贵妃《过华清宫》，与苏轼寓惠无关，两者不可同屏引用 | 《食荔枝二首》其二本文语势 | 误读，纠正【有据】 |
| "东坡肉是惠州菜" | 《猪肉颂》（"黄州好猪肉，价贱如泥土"）明作于**黄州**；惠州有据的肉食是**烤羊脊骨**（《与子由书》）；杭州"东坡肉"为后世菜名追认 | 两篇本文 | 【有据（黄州、惠事）】＋"东坡肉归惠州"【传说】 |
| "苏轼在定州酿中山松醪／《中山松醪赋》作于定州任上" | 维持项目既有结论：该赋非定州任上事。今人报章考证文互相打架（一篇把知定州系于绍圣元年，另一篇系于1093——后者是），且苏轼定州自撰诗文无酿酒一字；"中山"系郡名，后人因名附会。张舜民"满酌中山酒"只证明此酒为州土名物，不证明其所酿 | 报章内证＋定州自撰诗文检索无果＋前档既有判断 | 【后人附会】（游戏可用"任上饮中山土酒"，不可用"亲手酿松醪"） |
| "《独觉》'报道先生春睡美'触怒章惇，因而再贬海南" | 贬儋有绍圣四条政争之背景，"因诗再贬"出宋人诗话家传闻，确指成文者未核到 | 诗话传闻系统 | 【传说】 |
| "苏轼以卓锡泉酿酒／烹茶留题" | 卓锡泉地名真（唐僧传说入方志），但苏轼集中核无咏卓锡泉篇名 | 本会话核查（年谱、行迹考方向） | 【传说／存疑】 |
| "苏轼在定州、惠州断案如神、有判词传世" | 知定州时确有完整判狱权（真签判、真结绝），惠州时**一切署名皆无**——"空印"机制恰在于此；但两任皆无可靠判牍传世，市传"东坡判案"全部出自明清公案话本 | 《宋史》职官制度＋本传＋前档第四节结论 | 【传说】（判案权限本身为【有据】） |
| "六如亭对联、朝云前世即西湖侍妾、苏小妹与佛印斗法（延及惠州）" | 六如亭为后人因墓志"六如偈"语意追筑，亭联出明清；朝云前生"山河大地作微尘"之怪诞事出宋僧乘闲集偶及"无事常闲"之联语，非正传；与乌岩案株连之僧道（"僧人乘空（僧志行）"为另一人，非定州惠州事） | 前档"佛印—明清话本"切割原则 | 【传说】 |
| 定州今"东坡吊炉烧饼／口蘑东坡"等特产故事 | 无宋人依据，为现代地方物产营销 | 定州方向文献检索无果 | 【传说】 |
| "表兄文勋、杨世杰（定州都监）、田端（贬定州）" | 文勋核无其人（真表兄：程正辅；文与可已于1079卒）；杨世杰核无（疑为杨杰／杨世昌合并错记）；田端真宋人但与定州惠州无涉，其系狱在元丰乌台旧案——**三人在本两章皆不可入戏** | 本文档第三节 | 用户记忆错误【据上条】 |

## 附注·补核（成稿后补，效力优先于上文同条）

- **"表兄正辅"即程之才**：之才字正辅，母党表亲，娶轼从妹（轼为其主婚，宋人笔记载之，篇名未核【存疑】）；早年因姑家嫌隙**十二余年不相闻问**，绍圣中程之才差遣广东（宪/漕），**按临惠州，表兄弟复相见**，轼因得庇护——此事系苏辙《亡兄子瞻端明墓表》一路的宋人记载，游戏可入戏【有据（事）／篇名【存疑】：《墓表》原文措辞请核《栾城集》后再定台词】。上文第三节该表中凡涉"与程德孺书""程之楙"字样均作废：**德孺（程瑀?）、之楙皆我误记，勿采**；《次韵正辅表兄江行见桃花》诗题仍可采【有据】。
- **空印案两吏：张遇明、张之翰**。元祐八年十二月十四日敕："入内内侍省定州路都监、供备库副使张遇明冲替，与远小监当；都大elas提举常平、太常博士张之翰放罢。仍令安抚司根括定州公使库空印文状以闻。"（转运使张问奏"见任守臣于文状先印后书"之敕）【有据，《续资治通鉴长编拾补》卷八】。绍圣初安惇等追论此事为苏轼"罪"之一，轼在英州/惠州谢表中自称"去年中山，偶亦得之"（大意）之对狱经历【引语措辞以《长编拾补》原条目为准，勿照抄本文】。游戏"空印"机制的史实锚点即此两条。
- 上文第三节表内所有加了引号而标注"未核"的句子，引用前必须回校中华书局《苏轼诗集》《苏轼文集》，未回校前一律按【存疑】处理。

- **绍圣元年南行过岭的月份：无据**。本节表内原写"闰二月过梅关"—— **作废**：
  落职知英州在**闰四月**、责授惠州安置在**六月**（《宋史》本传），闰二月早于落职，时序不通；
  过梅岭（大庾岭）本身只有《过大庾岭》诗【有据】，**月份任何一本年谱都没记**。
  游戏侧现在只可写"绍圣元年南行，过梅关"，不许配月份；"十月抵惠州"照旧【有据】。
- **中山酒分级：【存疑】，不是【有据】也不是【传说】陷阱**。"满酌中山酒，重添丈八盆"（张舜民悼轼诗）
  只证明它是定州**州土名物**；"苏轼在定州酿松醪／《中山松醪赋》作于定州任上"是后人附会（见第四节）。
  本档第四节给的合规说法是"任上饮中山土酒"。游戏里它因此挂【存疑】、摊名"中山土酒"，
  而【传说】那一档**专留给现代追认的假历史摊**（东坡吊炉烧饼、口蘑东坡——买了要掉人情物议），
  两者不许混用：分级在《东坡行旅》里是带断言的数据字段，不是注释。

（完）
