# 《东坡行旅》开发规格（给实现方的 prompt）

## 0. 一句话
玩家**扮演 45 岁的苏轼本人**，从元丰四年的黄州出发，沿真实的贬谪路线走到儋州，一边走一边做菜、断案、收信回信、攒下一本食单。做出来是一个**能在 Windows 下双击 html 直接玩**的叙事 + 回合玩法游戏。

## 1. 硬约束（违反任何一条即返工）
1. **双击就能玩**：入口是 `东坡行旅/行旅.html`，同目录另有 `开始游玩.bat` 与 `从头再玩.bat`
   （目录里躺着六个 .html，别让人双击错哪一个）。禁止 ES module、禁止 fetch、禁止 Web Worker、禁止任何外链资源。
   两个 .bat 必须保持 **GBK/ANSI 编码且不带 chcp**（UTF-8+chcp 会让 cmd 把 start 腰斩——
   10-03 实栽过，闸在 `tools/check_launcher.py`，链上第 22 步）。
2. 图片是**同目录本地文件**，用 `<img src>` / CSS `url()` 加载（file:// 下可行）。
3. **只用系统字体栈**（宋体/楷体），不引 web font。
4. 存档用 `localStorage`，单档可覆盖，不联网。清档只有一个受控入口：`?fresh`
   （`从头再玩.bat` 带的参数，在 `loadGame()` 之前 removeItem），其余一律不许悄悄清。
5. 台词**一律用苏轼（或对应人物）真写过的句子与口气**，玩家只做选择。查不到出处的句子不许写。
6. 史实与传说必须分层标注，不许把明清话本当正史写。

## 2. 架构：HTML 主体 + Godot 当素材工厂
- 运行时**只有 HTML/CSS/Canvas**。
- `E:\godot\Godot_v4.7.2-stable_win64_console.exe`（导出模板 4.7.2 已装）**只用 headless 烘素材**：粒子（蒸汽、炭火星、雪、雨）、动画曲线、噪声材质，导出成**序列帧 PNG** 给 HTML 播。
- **禁止使用 Godot 的 Web 导出运行游戏**：已实测 `file://` 下加载器 fetch `.pck`/`.wasm` 被浏览器拦截（`Failed to fetch`，与 `thread_support` 开关无关）。
- 烘素材的工程放 `东坡行旅/_godot试/`，产物落 `东坡行旅/素材/`，工程本身不进游戏。

## 3. 美术：三层，一切给人物让路
**风格一致性 > 考据。** 题材可以古代，画法必须跟已定的人物卡面同源。

| 层 | 画法 | 用途 |
|---|---|---|
| 正史层 | 厚涂半写实卡面 | 主视图、对话、堂上 |
| 演出层 | 二头身 Q 版，厚涂绘本 | 吐槽、地图小人、灶前、采买 |
| 话本层 | 明清木刻绣像，**只有墨色与纸色** | 明清虚构的"东坡神探""佛印机锋" |

- **配色锁死**：朱红 `#b4472f`、石青 `#2f5d72`、织金，其余一律冷灰与浅米。
- **人物不入场景图**。场景一律空场产，立绘叠在前面。
- **立绘必须纯白底**：提示词写"背景是纯白色，没有任何渐变、没有任何阴影、地上没有投影"，再用 `tools/cutout.py` 从四边向内泛洪抠白（只抠与边框连通的白，人物内部的素白领口不会被抠穿）。**冷灰底 + 椭圆羽化已废弃**——在暖色场景上会露出灰色方块。
- **禁止让即梦写字**。地图、话本堂、市井横卷里那些空白匾额/招幌/立牌是故意留的，州名摊名堂名一律 HTML 叠字。

### 即梦提示词规范（产图前照抄结构）
```
[层名] + [画法与质感] + [主体：年龄/巾帽/衣色/纹样/手持物/神态] +
[构图：人物占画面左三分之二，右侧留净底] +
[光：柔和侧顺光，发丝须尖有冷色高光] +
[配色限定：朱红只出现在X，织金只作Y] +
[禁令：不要文字、不要印章、不要水印、不要现代物品、不要人物(场景图专用)]
```
- 模型固定 **Seedream 5.0 Lite**，驱动 `tools/jm_run.js`（改 `TAG`/`RATIO`/`PROMPT_FILE` 即复用）。
- 提交前**逐字断言**输入框内容（只比长度会被上一轮旧提示词混过去，已踩过）。
- 认图**按批次祖先节点 innerText 是否含本提示词前缀**，不要用 pathname 去重；轮询时**必须滚动结果区**触发懒加载。
- 一轮 4 张候选，先翻候选换主图，别急着重抽。

## 4. 界面
### 4.1 对话（基准已定，见 `_对话两帧.png`）
- 背景整体压暗（亮度 ≈0.46），**只有开口的那一位出现**，另一位退场。
- **左＝永远是我（子瞻），右＝永远是客**，不换边。
- 话盒：不透明黑，**右下角斜切**；名牌：斜切平行四边形，跟人所在那一侧。
- **逐句推进，一屏一句**，右下 ▼ 提示还有下一句；左上"跳过剧情"，右上"返回"。
- 两张脸绝不能被话盒盖住。
- 席间关卡要**另一套布局**：一桌多人时不能只出现说话的人，改成在座者都在、只切名牌与压暗态。
  **已实现**（`行旅.js` 的 `renderBanquet`）：三位在座常驻画面，选中者亮起、其余压暗（`filter: brightness(.72)`），
  名牌用 `ui-num` 资产写「欢 n/4 · 要听 X」；点客换靶→四张菜牌的绿色高亮跟着变。

### 4.2 顶栏
- 平时只有一行小字历书：`元丰四年 三月十七 · 午`。
- 数值变化时对应那根条闪一下即消失。**不做常驻数值条**（用户已否）。

### 4.3 布局切换
平时满屏场景；进灶前/堂上/席间**切成棋盘式专属界面**（两套 UI，这是已选定的代价）。

## 5. 系统
### 5.1 一个循环：时辰
每站若干天，每天三格（卯/午/酉），花完翻页。时间自动流向下一个贬谪节点。地图上的 Q 版小人挪一步要烧真实天数，途中触发驿站事件。

> **现状（审计 P3-3 补，2026-09-29）**：实做是**每章 6 个时辰**、不按"天"翻页 —— 三格那一版没做，
> 因为一章 6 手已经把四种关（堂上／灶前／席间／上街）排满，再切一层"天"只是多一个没人看的计数器。
> Q 版小人挪一步＝`#章/travel` 那一屏（真烧一拍），但**驿站事件没做**：路上那一屏只有小人、年数与一句真诗。

### 5.2 五根条
- **火候／此心安处**（全局心情，直接沿用旧线那根温度条）
- **银钱**：黄州每日限用 **一百五十钱**，余钱存大竹筒"以待客之不虞"（《答秦太虚书》，有据）——这就是每日预算机制
- **人情**（徐君猷、马正卿、朱寿昌）：换食材、换案源、换一次不被参的风险
- **物议**：写诗涨文名也涨风险，乌台诗案就是它爆表的下场
- **身体**：消渴疾（他晚年真患糖尿病、节食米面），从第四章起生效

### 5.3 三种关卡（复用旧线火候·戒备·阶段引擎，只换皮）
| 关卡 | 敌人 | 结构 |
|---|---|---|
| **灶前** | 柴、时间、来客口味 | 读帖（圈原文动词＝学菜谱）→ 守锅（火水时三量，只从画面读；设一个违反"莫催他"的**"催"按钮当陷阱**）→ 上桌（菜＝话，四维打客人弱点） |
| **堂上** | 说谎的人、缺的物证、押着的天数 | 质证出牌换线索，再出判牌 |
| **席间** | 三人各要听不同的一维 | 菜＝话，味·典·趣·情四维打客人所好；6 巡，三人各需欢 ≥4 |

菜谱就是原文：《猪肉颂》"净洗铛，少著水，柴头罨烟焰不起。待他自熟莫催他，火候足时他自美"＝五条约束；羊脊骨"渍酒中，点薄盐，炙微焦"＝三步。

### 5.4 两本册子
- **《食单》**：一道菜要凑齐 食材 + 一局灶前 + **一个同吃的人** 才收录，格子里存的是"那天跟谁吃的"。

> **现状（审计 P3-3 补）**：三个条件里只做了**两个半** —— 食材（上街买）与"做过/上过"（灶前成锅、席间上过）
> 都算数，而**"那天跟谁吃的"这一层没做**：册子只记一味菜名，不记同席的人。
> 这一条是设计里最值得做而最没人碰的一块（它要把 `S.got` 从集合改成带伴的表），留在下一步。
- **《清欢册》**：诗稿。断案判词、回信、灶前悟出的句子沉淀成诗。

### 5.5 印章＝身份（主线骨架）
- 黄州无官印可用，**"东坡居士"之号来自马正卿请得的那块废地**（《东坡八首》叙、陆游《老学庵笔记》）——玩家是在丢掉官衔那一站亲手拿到"东坡"这个名字。
- 元祐换官印，盖得响亮；绍圣后掉回私印；儋州几乎无印可盖。
- **"不得签书公事"做成机制**：判词写完，印落下去是空的，盖不出字，只涨乡望不涨政绩。
- 结局＝三枚章并排盖在一张纸上，配《自题金山画像》"问汝平生功业，黄州惠州儋州"。
- 界面署名：前期显示"苏子瞻"，黄州躬耕之后某一刻**突然**变成"东坡居士"，不解释，让玩家自己发现。

### 5.6 话本层
明清虚构（东坡神探、佛印机锋、苏小妹）做成**明确标注的幻想关卡**——"后人就是这么编你的"。里面真能上堂、真能斗嘴，出来回到无权现实。佛印**只在话本层斗嘴**，正史层只收他一封信。

### 5.7 两个文字机制（9-27 决定：**两层合一，只剩一个**）
- **插一句**：他书信里本来就常突然转题（报米价、讨药方、说羊脊骨），所以走神不是编的，是他的文体。
  不设入口，过完一关自己冒出来一格朱漆匾；三个选项全真句（其中一条是「别人以为他说过」的伪作），
  说真句涨人情入清欢册、说伪作扣物议、咽下去涨物议 —— **都不判输赢**。
- ~~补一句：诗稿收集时给三个选项~~ → **就是回信那一层**：信屏的三个选项**全是他真写过的句子**
  （可跨年），选错也成立，只改本章气质与后续诗句走向，不掺伪作、不设答错惩罚。
  既然同一个机制不该有两个名字，信屏标题从此写「补一句 · 回哪一句都算回过」。零新机制。

## 6. 卡牌可读性铁律（旧线踩过的坑，不得复发）
- 每张牌都要有玩家能看见的靶子；判定**在牌面上算给玩家看**（含数字），门槛不许写成谜语。
- 锅和客人都要**每回合亮 intent**（"此刻它要的是：别催"）。
- 菜牌实时打 ✓/○/△/✗ 角标。
- 保底动作不许是纯惩罚（旧线"且坐"＝弃一张重抽）。
- **验收标准：写一个只会读界面状态的贪心自动机，它能通关才算机制可读**；它必须背牌表就是还缺信息。

## 8. 史实纠正（写文案前必读，别再写错）
- **苏洵 1066 年已卒**，45 岁时不存在家书。家书对象是**苏辙**，另有王闰之、王朝云、苏迈·苏迨·苏过。
- **章衡不是笔误**：嘉祐二年状元、苏轼同年、章惇同族（行第宋载互异，只写"同族"）。章衡＝暖线，章惇＝刀线。
- "蓼茸蒿笋试春盘"是**开封期**《浣溪沙》，不是颍州；《中山松醪赋》是早年旧作，不挂定州。
- 羊脊骨帖写给**苏辙**，食蚝帖写给**苏过**；"此心安处是吾乡"出《定风波》小序，歌者名**柔奴**。
- 资料真源：`东坡行旅/调研/后半生年表与食单.md`（带【有据】/【传说】/【存疑】标记）。

## 9. 音效
**下载真素材，不要 WebAudio 自己合成**（用户明确指定）。浏览器有外但 Wikimedia 超时、OpenGameArt 通（20 支现役全出自它）；Pixabay 2026-10 起直链走播放器 JS 抓不到、淘声网搜索页空壳。**每条音效必须留档出处与授权页**（表在 行旅数据.js 的 SFX，流水在 _shots/sfx_log.jsonl）。文件不写死 .mp3：SFX 表带 `ext` 的按 ext 播（10-04 起，wav 原生可解；本机无 ffmpeg）。

## 十一、UI 与背景的融合（2026-09-24 晚·用户点名的问题）

**毛病**：把 `ui-panel` / `ui-num` 这类矩形条直接糊在场景上,和厚涂背景是两套语言,割裂。
**要的是**：玩家觉得这些数字／牌是**摆在那间屋子里的实物**,可以点。

**两条路,都走了：**

1. **给背景留空位**（`p_stove_bg2` / `p_hall_bg2` / `p_street_bg2`）
   提示词里把画面**硬分区**：上三分之二画场景,下三分之一写"一整片空旷干净、没有任何物件的青砖地面／街面,只允许有柔和的日光斜影渐变",右侧再留一条素净空墙。
   实测即梦**能守住这种分区指令**——`hallbg2-*` 甚至顺手在梁上画了一块朱框空白匾,`tools/measure_slots.py plaque` 能把它量出来当标题位用。

2. **生成"带 UI 的实物"再抠**（`p_rack` / `p_tray` / `p_bracket`）
   - `rack-1`：深色木多格架,六格内是素米色面板 → **它本身就是右侧面板**,数值直接印在格子里,不再叠 `ui-num` 条。六格的 y 区间由 `tools/measure_slots.py rack-1` 逐行扫出来(0.070~0.179 / 0.218~0.325 / …),CSS 里写成 `.slot.s1~.s6`。
   - `tray-3`：竹木牌架(一排插槽) → 摆在牌区底部、**DOM 顺序放在 deck 之前**,所以牌压住它下半截,看起来像插在架子里立着。
   - `bracket-1 / bracket-4`：朱漆匾带云头耳和挂绳 → 当标题匾、意图匾、锅况匾。字落在实测匾心(x 15%~85%, y 22%~76%)。

**踩到的**：架子顶上是回纹牙板,把"回合 1/7"压上去会糊 → 计数一律挪到牌区上方那行提示里,别指望资产顶部能放字。

## 十二、定州章（第二条线跑通）

### 章与章的差别只有一句话，但它改了玩法

黄州：`不得签书公事` → 堂上打的是「他有没有状纸」，牌面有**风险**栏，越过 `riskMax` 这判递不上去。
定州：`知定州军州事` → 他真的能判。所以堂上换成**空印**：

- 规则面板里写死那句：「这不是罪。—— 到绍圣元年，它是。」

1. **一张空印都不用也必须结绝得开**（实测 17/16）——否则「印不印」是系统逼的，不是玩家选的；
2. **用空印确实更省**（31 > 17）——否则诱惑是假的，没人会去权衡。

## 十三、惠州·儋州·终局（四章贯通，2026-09-25 凌晨）

### 堂上四章四种代价 —— 这是这一层的全部意义
换皮不算过关，验收里有一条**专门断言四章 `court.mode` 互不相同**：

| 章 | mode | 牌面上的代价 | 什么时候疼 | 对手是谁 |
|---|---|---|---|---|
| 黄州 | `质证` | `risk`（有 `riskMax`） | 当场越线 | 「你没有状纸」 |
| 定州 | `空印` | `yin`（+1 状） | **延到下一章** | 惯例 |
| 惠州 | `借印` | `ren`（当场扣人情） | 当场，且**上一章的债在这里收** | 自己的人情 |
| 儋州 | `问字` | `sh` / `body`（身体） | 当场，且**没有捷径牌可买** | 他自己 |

链条：`S.kongYin` 跨章不清零 → 进惠州时 `repay()` 按 `court.repay`（=8）折算成人情，下限 20。
验收跑一串债额 `空印 0/2/4/6/8/10` → 借印花掉的人情必须**单调不升且最后确实更少**（实测 42/42/28/16/16/16），
并且空印 10 状时必须**真的出现「借不动」**（实测 6 个回合手里有借印牌却点不动）。
这一条是设计能不能立住的命门：如果债压不动借印，定州那一枚枚印就等于没收利息。

## 十四、插一句 + 成就（两层早就定了、一直没做的东西）

### 插一句：他忽然转题
- **不设入口**。它不是 tab，是**自己冒出来**的一格朱漆匾（和「对手意图」同一块 `bracket-1`），
  过了第一个时辰之后每完成一关冒一条。理由：他写信本来就是写着写着就换成米价了 —— 有入口就成了待办清单。
- 每章 4 条，**全部是真句子**；其中一条 `lie:true` ＝ **别人以为他说过、其实不在他集里**的：
  黄州「一树梨花压海棠」（宋人诗话附会）、定州「三日断一百二十事」（明清公案话本）、
  惠州「东坡肉是从你这里传下来的」（《猪肉颂》明作黄州）、儋州「造墨、教黎人酿酒、与佛印隔海斗机锋」。
- 代价：说真句 → 人情 +3、进清欢册；说伪作 → **物议 -3**，清欢册里那条单独一个颜色（`.book .row.lie`）。
  咽下去 → 物议 +1，什么都不得。三个选择都不判输赢，只改这一章的气质。
- 验收三条：每章 ≥3 条；`lie` 那几条的 `src` 必须自己写明「传说／伪作」；真句子那几条必须带【有据】或【存疑】。

### 成就：一律用他自己的原句命名
- 不另造一套成就词。`DATA.achv = [{k, t, src}]`，`k` 是引擎 `ACHV` 谓词表里的一个键：
  `cook banquet dish letter clean frail poor noYin noBorrow taught saidLie hushAll`。
- **只列拿到的**，没拿到的不显示（否则章末变待办清单）。章末底下只有四格位置（再往上就压到印文），
  第五格折成「另有 n 句，都在这一章里」。
- 伪作那条成就故意给一句很美的：`saidLie → 「事如春梦了无痕。」`（黄州）——

## 十五、两份验收器：模拟器 + 真引擎（缺一不可）
- `tools/validate_cards.js` 是**照着 DATA 重算一遍**的平行模拟器。它绿了**不等于游戏能玩**——
  定州章 `playCourt` 少写 `break`（同一张牌能连打八次）它一直没抓到，因为发牌是它自己发的。

## 灶前：从「出牌」改成「一口活锅」（2026-09-26 夜 → 09-27 凌晨）

用户那句话是全部改动的因：**「烧菜也打牌？」**、**「总得有个玩法不能在那里干瞪眼吧」**、
**「切菜的案板、火炉等等都可以放在一张桌子上面」**、**「做烂了应该是变成一个东西，而不是就这么失败」**。

### 一份模型，三个入口
- `东坡行旅/灶前.js` 是唯一的真源：`ACTS`（二十来件案上实物）、`BOOK`（九道菜 × 四章）、
  `CHAPS`（一章一套案、一张背景、一套本地名）、`TIE`（读帖）、`ENDINGS`（五种结局）。
  浏览器挂 `window.ZAO`，Node 挂 `module.exports`。
- 三个入口共用它：**主游戏** `行旅.js` 的灶前屏、**原型** `灶前.html`（双击单玩）、
  **验收器** `tools/stove_greedy.js`。
- 「下一步做什么」也住在模型里（`nextMove`）：验收器与 `stoveAuto()` 调的是同一个函数。
  两边各写一遍迟早会漂，而漂了的后果正是那条老教训 —— 验收器绿着，玩家过不去。

### 玩法
- 一次下料 = 一拍，`act()` 内部自带 `tick()`，外面**不许再补一拍**。
- 锅每拍自己走：`gain = 5 + 炭×8 + (压盖?5:0)`，炭每拍衰减 0.22，越过火候上限就积一层糊。
  「你不动它，它也动」是这一屏唯一的玩法来源。
- **读帖挡的是手，不是分**：帖里没圈中的那件实物 `cap()` 返回 0 次，画面写「未读帖」而不是「余 0」。
  定州／儋州没有可靠原文，就**一道都不给帖** —— 没有原文就不硬造。
- **案板**：切一刀走一拍，换来入味 ×1.25、火候下限 -8。三条判定 ——
  该切的没切＝废；不许切的切了＝废；整颗下锅要比改过刀的多焖 2 拍。
- **「催」是陷阱**：《猪肉颂》明写「待他自熟莫催他」，所以它快、但一定烧糊，且身体低于 30 点按不动。
- 五种结局各配《猪肉颂》一句，**做坏了也有去处**（焦的送邻翁、夹生的自己拌饭、汤倒进沟里那条狗记得）。

### 画面
- 下三分之一是**一张桌子**：锅在左、读数在中、案上实物在右，手一伸都够得着。
- 背景那口锅与桌上这口撞成「两口锅」—— 解法是**景深**不是搬家：`#bg.deep` 虚 3.5px、压暗 .66。
- `起锅` 原来直接拿灶上那口陶 pot 当图标，一屏出现两次同一口锅；换成盛好的白瓷碗。
- 字一律落在不透明木牌上（背景是暖灰砖墙，浅色字直接压上去就是看不清）。
- 标题仍走全游戏共用的那块匾，读帖仍走那张宋纸 —— 这一屏看着还是这个游戏。

### 数据搬家
`行旅数据.js` 里四段 `stove` 的 `turns/lo/hi/scorchMax/start/status/cards/pose/tie/bodyNote/artFb`
**全删了**，只留 `dish / got / quote`（故事那一头）。留着那套数值，下一个人改了它发现画面不动，比删掉更贵。

### 验收

  本案凑得出 / 读帖真挡着 / 案板两条路。
- `tools/shot_stove.py`（跑验收.bat 第 10 步）：按 `#c=&d=&a=` 拍四间灶房 + 一张「切过之后的案板」，
  回读 DOM 确认读数、案沿两处都写成「已切 1 刀」，再把八个音各 load 一遍数能解码的几个。
- `tools/inventory.js` 的扫描清单加了 `灶前.js`／`灶前.html` —— 不加，案上那十几件会被当成闲置
  （图标接入选率 21/143 → 40/143，这才是真数）。

  故事那一头（时辰／人情／物议／食单收录／对话）照旧接得上。
- **`灶前.html`**：双击单玩的厨房，四章九道菜随便挑，**没解锁的也能试**（读数全是问号，只能靠「尝味」）。

## 十九、审计后落地的二十条口径（2026-09-27 下午，第七~十二条 9-28 补，第十三~十九条 9-29 补，第二十条 9-30 补）

写进规格是因为它们**改了以后做事的判断依据**，不是 changelog（逐条 file:line 在交接文档 §11）。

1. **存档是硬约束，不是待办**。`dp_xinglv_save_v1` 单档自动续玩；写档挂在 `layer()` 尾巴上
   （与获得提示同一条理由：点名式钩子一定漏掉后加的屏）。**带哈希的一律不读不写** ——
   验收路由跑一遍就把玩家进度覆盖成别章，**丢档比没档糟**。关卡内局面不存，半途那一锅不带走。
2. **得句与入册都必须"有归处"**。章配置 `verseWin/verseLose/verseFull/verseMiss/verseK` 的键
   必须 ∈ 本章 `book.verses`；摊与席的东西要么在 `book.dishes` 里，要么明写 `noBook`。
   名目对不上用 `book:` 别名（摊上「羊脊骨」＝册上「烤羊脊骨」），不许多立一行。
3. **台词的原文不可为了迁就机制而改**。《猪肉颂》三版并存的根因是"圈词要贴着文本" ——
   正解是**改圈词去贴原文**（少著水／柴头罨／火候足），不是改他的字。
   「待他自熟莫催他」留在帖上但不圈：它不是动作，是那颗雷的出处。
4. **一张桌子可以有多种桌面，但只能有一套引擎**。话本层（佛印机锋）借席间引擎，
   只在 `bnData()` 上换表、在 `b.dims` 上换维名；话本对白一律不标神情 `e`（绣像无五官，
   标了会被 FX 表换成厚涂脸，两层当场糊成一层）。
5. **验收必须有"不开 nodlg"的一条路**。过场白的续段（`say(k, then)`）在 nodlg 下**一次都不执行**，
   来信死循环就是这么在 141 屏全绿底下活下来的。现在双保险：静态扫源码对账 + 真人模式端到端四章。
6. **高清是一份写死的账，不是运行时探得出的事**。`file://` 不许 fetch，所以"谁有 1080 原件"
   记在 `高清清单.js`（`node tools/hd_list.js` 生成，别手抄）；`CUR_BG` 仍记逻辑名，
   匾面表按它查 —— **高清只换像素，不换身份**。
7. **位图的"能写字的地方"只有两种来源：量出来的，或者按包含块算出来的**。前者是背景上的匾
   （`素材/叠字框.json` 的 face），后者是我们自己的 CSS 件 —— 而 CSS 里**百分比的 `padding` 按包含块算，
   不按元素自己算**：舞台上那张 420 宽的纸写 `padding: 8%` 拿到的是 102px，正文只剩 215 宽的一窄条，
   截图上不出错、只是别扭。所以内边距一律写 px（`validate_cards.js` 有一条禁令会红）。
   推论：**"这张资产要落在量出来的面上"不是它可以一直闲着的理由** ——
   那只对"字叠在别人的画上"成立，木牌是自己的件、整张图当背景用也不需要 face 坐标。
8. **只有钉在 DOM 上的结论，才轮得到验收器去断言**。一屏画得对不对，看三个戳：
   `data-screen`（画的是哪一屏）、`data-board`（标题落进匾没有）、`data-clash`（标题框与自带纸的浮层相交多少）。
   凡"只有截图看得见"的问题，先把判据做成引擎自己在 `layer()` 里量一遍的结果，再让验收器回读 ——
   人眼过不了 149 屏，而"我这次裁图看到了"不构成下一次的防线。
9. **加一条分支，就要把每一个"全集分母"重问一遍**。`DATA.letters.length` 在成就、章末扣人情、
   章末计数、`demo()` 自动回信四处出现，接了 `after` 之后四处都成了不可能完成的数 ——
   其中一处是**造一条永远拿不到的成就**（与「没有一条成就是永远拿不到的」直接冲突）。
10. **戳要细到能区分"同一屏的不同内容"**。`data-screen` 只到屏名，于是 65 条 `#章/dlg/<键>` 路由
    全部静默播的是 `arrive` 第一句（boot 拿字面量 `"dlg"` 去查对话表，查不到就退回），
    二十二场对话 × 三章拍出来是同一张脸同一句诗，而验收一路绿。
    现在 `renderDlg()` 盖 `data-dlg="键#句序"`。**推论：屏名相同、内容不同的那一批（对话／信／册子／席）
    各自都需要一枚更细的戳，`data-screen` 不背这个锅。**
11. **量"看不看得见"只能量渲染结果，不能量素材原件**。第一版拿 `素材/高清/` 的匾面亮度加一个
    猜的 filter 系数（`#bg.deep` = brightness .66）判字色，六条里误判四条：
    ① 原件那个数不是屏幕上那个数；② 匾心混着织金回纹，均值被边角拖偏；
    ③ **"剔掉接近字色的像素再取中位数"会替错的那一条说话** —— 底与字本来就近的时候，
    剔完剩下的是高光，量出来偏亮，于是把"看不见"读成"刚好及格"。
    正解：引擎把标题方框与字色钉成 `data-ink`，脚本对那块像素取**全集中位数**（笔画占不到一半）。
12. **验收要有一趟不是冷启动的路由**。169 屏全是刚进章那一格：食单九行全「未见」、银钱永远三位数、
    信一封没回。而会长、会挤、会溢的东西只在中后段出现 —— 章末第五格成就整张挂在画外，
    就是 `#章/屏/full`（`fillAll()`）那一趟抓出来的。
    ⚠ **"填满"类 dev 钩子自己就会把要拍的东西填满到不存在**：第一版把信全回完，
    `pending()` 空了，`#章/letter` 反而静默退回 hub。留一封没回的。
   口径：门槛只落在"收得到吗"这一层（`mailOpen()`／`mailTot()` 各一处，别在画墙那一层各挑各的），
   可达性用**不动点**算成断言，而不是靠人记得。
13. **改版要表达的东西不许锁在控制台后面**。分支信墙的整个卖点是「换一句回法，墙就不一样」，
    而看到另一条墙只能重开一局 —— 于是「重开」这个动作本身变成了内容的一部分。
    清档不能要求玩家按 F12：给它一个双击的 `从头再玩.bat`（引擎侧只是 `?fresh` 一道，
    落在 `loadGame()` **之前**），并播一枚 toast 让玩家分得清"重开了"与"又开了一次"。
    **推论：交付清单里"怎么开始／怎么重来"与"能不能通关"同级** ——
    六个 .html 躺在一起的目录里，玩家双击错文件、或者根本不知道怎么重开，
    跟一个 bug 一样会让内容看不见，而验收器一条都报不出来。
14. **验收器不许替引擎圆谎：「存在性」也要有 DOM 戳**。审计二期三条 P1 全是同一个形状 ——
    笔记写着「炭会自己烧，你不动它也动」，可全项目只有一个管 toast 的计时器；
    贪心线与 harness 都用 `act()` 内部那一拍驱动，**恰好绕开了"没有定时器"这个事实**，于是验收一路绿。
    同款第二例：真人模式从 `DP.act("chap")` 进章，而玩家双击走的是 `reset()+loadGame()+renderHub()`，
    章首白就在那条没人走过的路上丢了。**推论：凡是"某件事真的会发生"这类断言，必须有一个只有它会发生时才有的戳**
    （灶前那枚 `data-pot="拍/总拍"` 就是这么来的：`#章/stove2/live` 断言它 >0，其余灶前路由断言它 ==0）。
15. **册子上承诺"可得"的每一行，要么真拿得到，要么明写拿不到**。清欢册曾有七行挂着「待触发」
    而全引擎没有任何一条路能点亮它 —— 玩家读到的是"再玩玩就有"，真相是"这一局不会有"。
    修法不是删句子（那是拿史实换表格好看），是**三条补真的入手路**（黄州《猪肉颂》←做成那一锅、
    定州／儋州章首句←开篇读到）＋**四条改文案为「这一章没走到」**，再加一条断言：
    每一行要么可达、要么明标，两头都不占就红。**通用口径：任何"进度型清单"都要能被机器问一句"这一格怎么亮"**。
16. **文案不许替自己做史实判断**。二期挑出的六处全是同一类执行 slip：把系年写成定论
    （《纵笔三首》其一标"惠州作"）、把后人附会写成【有据】（中山松醪"曾寄雄州守"）、
    给自己没核到的人名（"林夫人"）、把"未回校前不入正文"的那句排在正文里。
    规则本身没问题（黄州章逐句核过是干净的），**出问题的是"没有台账的【有据】"** ——
    **SSOT 断言已立（9-29 上午，补档在前）**：`调研/` 现在有三份档 —— 两份年表记"事与物"，
    `篇名台账.md` 登记"游戏引过的篇名"（只说引过，不说核过）。`validate_cards` 的 SSOT 章要求
    数据里 `src/note/lic` 出现的每一个《篇名》都在三份档之一命中，否则红。**加引文的正确顺序是先补档再改数据。**
    配套还有第四份档 `调研/待回校清单.md`：由 `tools/ssot_pending.py` **从数据现读生成**，
    把所有自己承认没核完的引文按"要核什么"归堆（卷次／系年／字句／真伪／人名），带 `结构路径 :行号` 可跳。
    它是 `跑验收.bat` 第 15 步（`--check` 只对数）—— **能生成的东西不许手抄**，与 `高清清单.js` 同一条规矩；
    清单里"真伪"那一堆另有一张人写的判断表 `tools/triage_zhenwei.tsv`（留／降／撤），
    `--check` 同时要求**每条真伪都分过诊、表里不许有孤儿行**。两个细节定了规矩：
    ① **判据是"这句话站在哪儿"，不是"src 里有没有'传说'两个字"** —— 断言在 disclosure 里就是做对了，
    在人物的第一人称嘴里才是问题（儋州那句「海南第一个应举的人」就是这么降的）；
    ② **表的键是前缀（`startswith`），不是定长窗口** —— 在句尾补一句话就把判断冲掉，等于逼人乱填。
    而"查完了"的验收动作不是打勾，是回数据把那句 src 补成【已核，卷 N】再重跑生成，**清单变短才是进度**。
17. **"越出舞台"不等于"看不见"：定高容器吃内容，要拿容器自己的底去量**。册子那张纸 420×500 带
    `overflow:hidden`，纸底离舞台底还有 110px —— 内容淌出去 100px 以内时，`cut`（只查**自带文本**的元素，
    而册子的字全在 `<span>`/`<i>` 子节点里）与 `out`（只查 1280×720）**两条都不沾**，
    于是儋州清欢册少画了两行插一句而验收全绿。现在多一条 `spill`：`fitBookPages` 每屏量完把
    `data-fit="窗口高 / 这一叶画到多高"` 钉在 `.brows` 上，后者大于前者即红 ——
    "拦腰切一行"与"压根没人量过"两种坏都红在这一条上。
    同一条形状的东西**合并成一个出口**：三屏（清欢册／堂上规矩／案情）以前各抄一份 `.book` 的 HTML，
    现在都走 `bookPaper()`；抄三遍的时候静态断言只能盯字面，盯不住"三处是不是同一张纸"。
    交互也要有路由才叫验过：`#章/verses/p2` 拍的是"下一叶真点得动、翻过去确实有内容"，
    **只拍第一叶等于没拍这条交互**。
18. **静态扫不剥注释，等于把"注释掉"当成"没做过"**。证伪 `layer()` 里那一行 `fitBookPages();` 时，
    我把它改成 `// fitBookPages(); ← 证伪`，字符串还在，断言照过、当场没红。
    现在凡是拿函数体去 `test()` 的断言，一律先 `replace(/\/\*…\*\//)` 再 `replace(/\/\/…$/)`。
    （同一条也救了一次假绿：`fitBookPages` 的**注释**里本来就写着 `data-fit` 三个字。）
19. **素材是"一整卷"还是"一下"，是验收器看不见的一类**：`check_audio` 只验"解不解得开"，
    而 `paper` 那支 9.59 秒里装着 10 次翻页、`lid` 8.14 秒是一串 thwack —— `sfx()` 原来只有
    `currentTime = 0; play()`，**没有"到点停"**，于是玩家每翻一页纸听到的是整卷十次翻页。
    现在非循环的一律有上限（默认 1.5 s，数据里 `cap` 逐支覆盖），`check_audio` 把"全长 → 一响"排成一张表。
    **能算出来的才钉死**：`paper`＝10 次／9.59s ≈ 0.96、`taste`＝7 次／6.90s ≈ 0.99，事件数就写在授权行的标题里；
    剩下 card／water／brush／gavel／seal／cold 是**素材不对味**，cap 只止得住"太长"，止不住"不像" —— 那要耳朵。
    同一条形状还修了一次判据自己的错：第一版拿**默认** 1.5s 去比素材长度，0.34 秒的 gavel 被判成
    "cap 是摆设"，一口气五条假案 —— **只有显式写了 cap 的才有资格被判错**。
20. **"一次性过场"的闸要按章记，不按全游戏记**：`S.flags.edict` 原来是 0/1，
    开场那一屏只有黄州一纸时看不出问题；定州补了第二纸之后，黄州看完就把定州那一屏一起吃掉了 ——
    **一个 flag 服务 N 章，等于只服务第一章**。现在按章记（`edictSeen()`／`edictDone()`），
    旧档那个数字 1 认作"黄州看过"，不让老玩家白丢新章的那一屏。
    同一次改动照出两条断言在抄文案：harness 把落点写死成 `hub`、把那句「印是空的」写死在正则里，
    定州一上就红。**断言照数据读，不抄文案**（`EDDICT[k].thesis`、落点 `EDDICT[k] ? "edict" : "hub"`）——
    与 §34「能生成的东西不许有两个生成者」是同一件事：**抄的那一份一定会漂**。

## 二十、尝菜 · 录方（2026-10-02，把 `bill-*`／`tast2-*` 两批死资产接活）

**这一屏存在的理由**：灶前那口锅只能"章内三尝"，尝出来的方向从来没地方**落成方子**；
`S.recipes` 与菜数据的 `known` 字段从第一天就在盘上、一直没人读。
尝菜屏就是把"尝出来的夹逼"变成"写得下的方子"那一格 —— `known` 从此是活的。

**口径（不许漂的几条）**
- 入口挂在**食单屏**左栏，是**文字页签**（与「归案」「音」同款）。
  不许做成"图标 + 悬停才出名字"：`.tab.ic .tip` 是 `opacity:0`，截图与触屏里等于没标签。
- **一口 6 文**（`ZAO.REC_FEE`）。定价是设计不是尾数：一道菜从空表夹死要 6～8 口＝36～48 文，
  一章攒得到的银钱只够录一两道，玩家要**选哪道菜值得不再猜**。
  闸 `check_recipes.js` ⑤ 钉的是"最贵一道不超过一章能攒到的数"，定到 12 文这条机制就等于没有。
- **未录方的菜，灶前读数条真的把区间藏起来**（`knownOf()` 假 → `zmeter` 不印 `低–高`、
  量表走盲读档）。不是"印出来但灰掉"：灰掉的字还是读得到，那这条设计就没生效。
- 存档结构存**夹逼结论**不是流水账：每道菜每味只存四个数（不足的最高读数／正好那一段的两端／过头的最低读数）。
  加一条只会收紧 —— 早先那版"一条一口 + 24 条上限"会把已夹死的一味**重新松开**，是退货玩家挣来的信息。
- 候选假区间**必须互不相交**（偏移＝宽度+1）。重叠的候选只有"正好尝在边界上"才排除得掉，
  实测 45 味里 39 味永远夹不死。
- DOM 锚点 `data-taste="<菜>/<夹死>/<总>/<已填夹位格数>"`，只在 `#章/taste` 那一屏非空。
  第四格**不是口数**（同侧再尝一口不涨），别拿它当"花了几个银钱"的证据。

**资产接到哪一格（要说实话的那半）**：`tast2-*` 48 张里可达 **27**、`bill-*-cut.png` 16 张里可达 **9**，
因为每章菜数是 3/2/2/2 而素材画到了 4 号。
**不许把 `idx+1` 改成取模来"清空槽"** —— 那会让两道菜共用一张桌景，等于用假接线换掉一个空槽；
要点亮第 4 号只有一条正道：**给某一章加第四道菜**。

**深状态（`#章/屏/full`）不许与冷启动同一张图**：`fillAll()` 必须给尝菜屏留下三种桌景各一道 ——
第一道留白（冷桌＋「还差 5 味」）、中间那道夹一半（`ing`）、最后一道夹死但**不写 `S.recipes`**
（`ok` 桌景＋「定方」那颗钮；写了钮就消失）。读数用 `ZAO.probeAt` 落在真区间中点，
**不许手搓数字**（手搓会造出"看着锁住、其实三格里还活着两格"的假深状态）；
停在最后一道靠 `S.dial.d`，不新增路由。与"留一封没回的信"是同一条规矩。

**一条从崩里学来的口径**：任何会调 `zn()`（灶前流水）的动作，它所在的屏必须能在**新开的那一页**上直接按。
`S.zao` 原来只在起锅那一路赋值，于是尝菜屏的「尝这口」「定方」在双击进来的玩家手里是死的
（`undefined.unshift` 一条 TypeError，界面上什么也不发生）。
规矩：**动作要用的状态，得由 `reset()`/`S` 字面量保证存在**，不能依赖"玩家先去过哪一屏"——
与"能生成的东西不许有两个生成者"同源：**靠别人顺手初始化，一定会漂**。
验收侧同一条：`shot_game` 只画不点，`engine_harness` 的段序会把前一段的初始化带进后一段 ——
**要验"能不能点"，必须从 `bootFresh()`（无哈希、无前置动作）那一份实例点下去。**

**验收（本轮新增两条）**- `tools/check_recipes.js`（第 17 步）：可夹死 ≤10 口 / 夹到的就是帖上那一格 / 单调不降 /
  只靠灶前三尝能夹死多少（**只报数不判红**）/ 费用可承受。`REC_FALSIFY=1` 三条判红。
- `tools/check_convergence.py`（第 19 步）：`shot_game.py` 两趟**并写同一张** `_screens.json`，
  所以"434 条"不证明两趟拍到同一批路由。这条按趟拆开比：路由集合相等、
  成对两侧都落盘且屏号相符、尝菜屏两趟各 ≥4 条（**下限写绝对值**，写比例在 0 条时恒真）。
- `engine_harness.js` 的两条：贪心机**只读界面**把五味夹到 5/5，且每口的 `data-taste`
  与从 HTML 行里数出的 `.trow ok` 对得上；离开那一屏锚点清空。

## 二十三、生命感包 · 自由行 · 两道菜（2026-10-03）

用户一句话：「合理完善我们的项目 使其成为一个真正的游戏。」美术诊断（2026-09-27）四病里
工程能到的部分一次做完；E（立绘重抽）、F（话本层做绝）仍旧待拍板，本轮没动。

### 生命感五件的口径

1. **屏间过渡**：`zswap` 淡入 + 落 12px（.27s）。落点是"翻开下一页"，不是"滑进另一个房间"；
   prefers-reduced-motion 照旧全关。
2. **按钮弹性**：`:active` 缩 .94 即时、回弹走 easeOutBack 系 —— 按下是实的，弹回是弹的。
3. **天气**：`#fx` 层挂在 #scrim 与 #layer 之间（雪压场景、不压界面）。定州雪／惠州雨，
   **只落户外三屏**（今日/上街/行旅），室内必停——室内飘雪是穿帮不是氛围。
   落点用固定种子伪随机（种子 42）：两趟验收拍同一路由，图要能对得上。
   戳：`data-fx = snow|rain|""`，engine_harness 四章八屏断言。
4. **今日屏住户**：四章各一位 Q 版东坡（dp45-3 掌勺／dp57-3 官袍／dp58-1 拄杖携荔／dp62-1 坐读），
   `pointer-events:none`（hit 闸摸不到）、idle 是呼吸不是跳舞。戳：`data-qb`（文件名），
   跨章不许换脸照旧是硬约束。**图一律走 `artSrc()`，别再手拼 `素材/` 前缀**——
